# Bouncy Star

공이 **저절로 통통 튀고**, 플레이어는 **좌우 이동만** 조작해서 맵의 **별을 모두 모으면 클리어**하는 2D 퍼즐 플랫포머예요.
설치 없이 `index.html` 하나만 더블클릭하면 실행돼요.

> 바운스볼 장르에서 아이디어를 얻은 **오리지널 게임**이에요. 원작의 이름·이미지·사운드·스테이지는 쓰지 않았고, 그래픽은 모두 도형으로, 효과음은 Web Audio로 직접 만들었어요.
> 작업 명세: [`BOUNCE_BALL_SPEC.md`](BOUNCE_BALL_SPEC.md)

## 실행

- `index.html`을 브라우저로 열면 바로 플레이할 수 있어요 (서버·설치 불필요).
- GitHub Pages로 배포할 때도 이 파일 하나만 있으면 돼요.

## 조작

| 입력 | 동작 |
| --- | --- |
| ← / A, → / D | 좌우 가속 |
| R | 현재 스테이지 다시 시작 |
| Esc / P | 일시정지 |
| M | 소리 켜기/끄기 |
| 모바일 | 화면 왼쪽 절반 = 왼쪽, 오른쪽 절반 = 오른쪽 |

## 블록

| 글자 | 블록 | 동작 |
| --- | --- | --- |
| `#` | 기본 | 윗면에 닿으면 튐 (약 3.4칸 높이) |
| `*` | 별 | 모두 먹으면 클리어 |
| `^` | 가시 | 닿으면 실패 |
| `J` | 점프 | 약 6칸 높이로 튐 |
| `C` | 깨짐 | 한 번 밟으면 무너짐 (재시작 시 복구) |
| `<` `>` | 대시 | 벽에 닿을 때까지 그 방향으로 날아감 |
| `O` | 순간이동 | 짝꿍 `O`로 이동 (맵 순서대로 2개씩 짝) |

스테이지는 10개이며, 새 블록을 한 스테이지에 하나씩 소개해요.

## 코드 구조 (`index.html` 안 `<script>`)

1. 상수 — `PHYS`(물리 값은 여기서만 바꿈), `TILE`, `COLORS`
2. `STAGES` — 맵 문자열 (24×13)
3. `Level` — 맵을 읽어 블록·별·시작점 생성, `reset()`
4. `Ball` — 이동, 그리기 (튈 때 납작해지는 squash)
5. 충돌 — `moveX()` → `moveY()` 축 분리, 이동량을 반지름 이하로 쪼개 뚫림 방지
6. 저장/불러오기 — `localStorage` (try/catch, 막혀도 동작)
7. 효과음 — Web Audio API로 직접 생성
8. 화면 효과 — 파티클·잔상·흔들림
9. 입력 — 키보드 + 터치
10. 게임 상태 — `'title' | 'select' | 'play' | 'pause' | 'clear' | 'end'`
11. 게임 루프 — 물리는 고정 1/60초, 그리기는 `requestAnimationFrame`

1~5번은 `// ==SIM START==` ~ `// ==SIM END==` 구간에 있고 DOM을 쓰지 않아요. 그래서 아래 검증 도구가 **게임과 똑같은 물리 코드**로 시뮬레이션할 수 있어요.

## 검증 도구 (Node.js 22 이상)

```bash
# 모든 스테이지를 실제로 깰 수 있는지 입력 조합을 탐색해서 확인
node tools/verify-stages.js          # 전체
node tools/verify-stages.js 6        # 6번만

# 헤드리스 Chrome/Edge로 페이지를 열어 조작·화면 전환·콘솔 에러 확인 (+ 스크린샷)
node tools/browser-check.js "C:/Program Files/Google/Chrome/Application/chrome.exe"
```

`browser-check.js`에서 확인하는 항목: 키 이동, 키를 떼면 멈춤, 자동 튐, 일시정지, R 재시작(별·블록 복구), 60Hz/144Hz 물리 속도 동일, 클리어 팝업·저장, 낙사 재시작, 엔딩, 모바일 세로·가로 잘림, 터치 조작, localStorage 차단 환경, 콘솔 에러.
